# Contributor instructions

Read `.github/copilot-instructions.md` before you edit files.

## Guidelines for contributors

- Keep changes small and focused.
- Do not edit files outside your assigned task.
- Follow existing code conventions and formatting rules.
- Add or update tests when you change behavior.
- Run the smallest relevant checks before you finish your work.
- Do not add new dependencies without an explicit requirement.
- Do not commit secrets, generated build artifacts, or local configuration files.
