Work method for this task. Follow it exactly.

1. Before changing anything, list every unit the request covers (every directory, file or item), and every rule or requirement that applies to each. Write that list to a scratch file as a checklist table with one row per unit and one column per rule.
2. Fill in every cell by reading that unit's own sources. Never infer a cell from a neighbouring unit, however similar it looks. Where a rule can be checked mechanically, write a small script that extracts the facts for all units at once and compare its output with the specification text for each unit.
3. Only then make the fixes, one unit at a time, re-reading that unit's own specification immediately before editing it.
4. After editing, re-verify every cell of the checklist, including the ones you did not touch, and run the existing tests.
5. Do not report completion until every cell has been checked. In the final answer give the count of cells checked and the list of fixes. Delete the scratch file before finishing.
